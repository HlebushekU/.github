## ООО «Хлебушек» 🍞

Хлебопекарное производство: три цеха — хлебный, булочный, слоечный, — доставка по маршрутам и собственная сеть магазинов.

Здесь живут внутренние системы предприятия: CRM для экспедиции, транспорта, производства и магазинов, интеграция с 1С и приложения для водителей и продавцов.
